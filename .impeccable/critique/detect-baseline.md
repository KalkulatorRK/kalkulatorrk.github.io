# Impeccable detect baseline

Generated by `npx impeccable detect` on main HTML calculators.

## Top recurring issues
- **low-contrast** — many text/button pairs fail WCAG AA (e.g. white on #3498db, #95a5a6 on white)
- **side-tab** — thick colored left borders on card-like blocks
- **nested-cards** — cards inside cards on index
- **skipped-heading** — h1 followed by h3
- **ai-color-palette** — purple/violet accents detected on index

## Priority fix order
1. Contrast on primary buttons and body/muted text
2. Remove side-tab accents; flatten nested cards
3. Fix heading outline
4. Replace AI-default purple accents with intentional palette from DESIGN.md
