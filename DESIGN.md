# Design system — Калькулятор РК

## Mode
Operate (tool UI). Clarity > decoration.

## Direction
Инженерный инструмент: спокойная нейтральная база, один чёткий акцент (синий/индиго технического спектра — не фиолетовый «AI default»), выразительная но не декоративная типографика. Без flat single-color «пустого» вида на лендинге, но калькуляторы — плотная рабочая форма, не hero-витрина.

## Color
- Фон страницы: светлый нейтраль с лёгким холодным оттенком (не кремовый terracotta-bias, не чисто #fff-only без структуры)
- Текст: почти-чёрный с холодным оттенком (не #000 чистый, не #95a5a6 для body)
- Акцент: насыщенный синий с контрастом ≥4.5:1 для белого текста на кнопках (уйти от #3498db + white, если контраст <4.5)
- Ошибки / предупреждения: отдельные семантические цвета с AA-контрастом
- Запрет: purple/violet градиенты, cyan-on-dark glow

## Typography
- Не Inter / Roboto / Arial / system-ui как единственный стек для display
- Читаемый UI-шрифт для форм; иерархия: заголовок страницы → секция → лейбл → значение результата
- Не пропускать уровни заголовков (h1→h2→h3)

## Layout
- Карточки только если они реально группируют взаимодействие (форма / результат)
- Не вкладывать card в card
- Убрать side-tab borders (`border-left: 4–5px` + radius как «AI tell»)
- Ритм: единый spacing scale; результат визуально доминирует над вторичными подсказками

## Components
- Inputs: явные лейблы + единицы рядом
- Primary button: один на главный action
- Help: collapsible / inline, не стена текста в первом viewport

## Motion
- Минимум; только feedback (focus, expand help). Без bounce/elastic.
